# 💡 인사이트 카드 뷰어 (Insight Card Viewer)

철학, 심리학, 경제학 분야의 깊이 있는 명언과 인사이트 문구를 매끄러운 3D 전환 애니메이션과 함께 탐색하고, 마음에 닿는 문구를 내 북마크에 보관할 수 있는 인터랙티브 웹 애플리케이션입니다.

---

## 🚀 깃허브 Pages (GitHub Pages) 배포 안내

GitHub Pages에 배포할 때 폴더 경로 문제 없이 바로 실행될 수 있도록 2가지 배포 옵션을 제공합니다:

### 방법 1. 단일 파일 초간단 배포 (가장 추천 ⭐)
경로나 폴더 구조 누락 걱정 없이 가장 확실하게 배포하는 방법입니다:
1. `standalone.html` 파일의 이름을 `index.html`로 변경합니다.
2. GitHub 저장소의 `main` 브랜치 루트에 업로드하고 커밋합니다.
3. GitHub 저장소의 **Settings > Pages > Branch: `main` / `root`** 를 선택하고 Save를 누릅니다.
4. 배포 완료 후 제공되는 링크로 접속하면 100% 즉시 정상 작동합니다!

### 방법 2. 전체 폴더 구조 배포
1. 아래 파일 및 폴더 전체를 GitHub 저장소 루트에 업로드합니다:
   - `index.html`
   - `css/` 폴더 (`css/style.css`)
   - `js/` 폴더 (`js/data.js`, `js/app.js`)
2. GitHub 저장소의 **Settings > Pages**에서 배포합니다.
   *(모든 경로는 GitHub Pages 서브패스 호환 상대경로 `./`로 설정되어 있습니다.)*

## 🌟 주요 기능 및 3D 효과 개선 사항

1. **강력한 3D 카드 전환 애니메이션**
   - **덱 스와이프**: 카드가 3D 공간 깊숙이 멀어지며 회전(`rotateY(-28deg)`)하고 새 카드가 입체적으로 착지하는 모션
   - **3D 플립**: 카드가 90도 회전하며 뒷면에서 새로운 통찰이 등장하는 효과
   - **인터랙티브 3D 틸트**: 마우스 이동 및 모바일 터치에 반응하는 역동적인 3D 각도 조절

2. **클릭 반응성 & 브라우저 안정성 강화**
   - Web Audio API 지연 로딩을 적용하여 브라우저 자동재생 정책으로 인한 스크립트 중단 완벽 방지
   - 전환 락 안전 타이머(Safety Watchdog)를 탑재하여 연속 클릭이나 탭 전환 시에도 버튼이 절대 먹통 되지 않음

3. **60여 개의 엄선된 지적 통찰 데이터베이스**
   - 철학 (니체, 아우렐리우스, 사르트르, 스피노자 등)
   - 심리학 (카를 융, 프랭클, 아들러, 프로이트 등)
   - 경제학 (애덤 스미스, 케인스, 슘페터, 탈레브 등)

4. **'내 북마크' 컬렉션 서랍 & 편의 도구**
   - 단축키 <kbd>B</kbd>로 북마크 저장 및 우측 서랍에서 모아보기 (로컬스토리지 영구 보관)
   - 문구 원클릭 클립보드 복사 (<kbd>C</kbd>)
   - 인스타그램/배경화면용 1200x1200 고해상도 카드 이미지(PNG) 다운로드
   - 사운드 온/오프 (<kbd>M</kbd>)

## ⌨️ 키보드 단축키

| 키 | 동작 |
| :--- | :--- |
| <kbd>Space</kbd> / <kbd>Enter</kbd> / <kbd>→</kbd> | 다음 인사이트 보기 |
| <kbd>←</kbd> | 이전 인사이트 보기 |
| <kbd>B</kbd> | 현재 카드 북마크 토글 |
| <kbd>C</kbd> | 현재 인용구 클립보드 복사 |
| <kbd>M</kbd> | 효과음 켜기 / 끄기 |
| <kbd>Esc</kbd> | 북마크 서랍 닫기 |
